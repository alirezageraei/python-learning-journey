# Error Handling in Python

A complete guide to exception handling in Python with practical examples.

## Topics Covered

- Basic try-except
- Handling specific exceptions (FileNotFoundError, ValueError, ZeroDivisionError)
- else and finally blocks
- raise statement
- Custom exceptions
- Stack trace propagation
- Context managers (with statement simulation)

1. **File Reader** – Handling missing files
2. **Safe Division** – Catching ZeroDivisionError
3. **Input Validation** – Looping until valid input
4. **List Index Check** – IndexError and TypeError
5. **File Line Counter** – else and finally usage
6. **Password Validator** – raise custom error
7. **Square Root** – Stack trace with raise
8. **Custom Exception** – BankAccountError
9. **ManagedFile** – try-finally pattern
