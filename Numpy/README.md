# NumPy Tutorial for Beginners

This repository contains three Jupyter notebooks that cover the fundamentals of NumPy.

## 📓 Notebooks

| File | Description |
|------|-------------|
| `01_array_creating.ipynb` | Creating arrays: `arange`, `linspace`, `zeros`, `ones`, random arrays, and joining arrays |
| `02_index_slicing.ipynb` | Indexing and slicing, boolean indexing, and working with structured arrays |
| `03_dtypes.ipynb` | Data types, casting, overflow, and how to choose the right type |
