# NumPy Tutorial for Beginners

A complete collection of Jupyter notebooks for learning NumPy from scratch — includes theory, practical examples, and 20 graded exercises.

---

## Notebooks

| File | Description |
|------|-------------|
| `01_array_creating.ipynb` | Creating arrays: `arange`, `linspace`, `zeros`, `ones`, random arrays, joining arrays, and more |
| `02_index_slicing.ipynb` | Indexing, slicing, boolean indexing, fancy indexing, and structured arrays |
| `03_dtypes.ipynb` | Data types, casting, overflow, precision, and choosing the right dtype |
| `04_copy_view.ipynb` | Understanding NumPy views vs copies — when changes affect the original |
| `05_universal_functions.ipynb` | Universal functions (ufuncs), reduction, accumulation, and `out` parameter |
| `06_numpy_exercises.ipynb` | **20 exercises in 4 levels** — from beginner to advanced topics |
